# استمع وتحدث - تطبيق تخاطب للأطفال

## وصف التطبيق
تطبيق تخاطب تعليمي للأطفال على شكل لعبة. بدون باك إند - كل البيانات محلية (localStorage).

## الهوية البصرية
- **الاسم:** استمع وتحدث
- **الشعار:** برنامج تعليمي للأطفال
- **الألوان الرئيسية:**
  - أخضر: #4CAF50 (رئيسي)
  - برتقالي: #FF9800 (ثانوي)
  - أزرق: #2196F3
  - أحمر/وردي: #E91E8C
  - أصفر: #FFC107
- **الخطوط:**
  - عربي: Tajawal (Google Fonts)
  - أرقام/عناوين: Fredoka One
- **الاتجاه:** RTL (عربي)

## هيكل الملفات

```
/
├── index.html         ← شاشة البداية (Splash + تسجيل دخول)
├── map.html           ← خريطة المستويات
├── game.html          ← شاشة اللعبة (التخاطب)
├── profile.html       ← ملف الطفل والإحصائيات
├── style.css          ← CSS مشترك
└── data.js            ← بيانات اللعبة (محلية)
```

## ترتيب البناء
1. `style.css` - أول حاجة
2. `data.js` - ثاني حاجة
3. `index.html` - ثالث
4. `map.html` - رابع
5. `game.html` - خامس
6. `profile.html` - سادس

## المتطلبات العامة
- موبايل فقط (max-width: 430px)
- بدون باك إند - localStorage فقط
- RTL بالكامل
- يشتغل offline
- لا يحتاج إنترنت إلا للخطوط
