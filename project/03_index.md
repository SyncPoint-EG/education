# SPEC: index.html — شاشة البداية

## الملف: `index.html`
أول شاشة يشوفها المستخدم. بتتحقق إذا في مستخدم محفوظ أو لا.

---

## المتطلبات
```html
<link rel="stylesheet" href="style.css">
<script src="data.js"></script>
```

---

## المنطق (JavaScript)
```
عند تحميل الصفحة:
  if getUser() موجود:
    → اعرض شاشة الترحيب (Welcome Back)
  else:
    → اعرض شاشة الإنشاء (Create Profile)
```

---

## الشاشة 1: Splash (تظهر لمدة 2 ثانية أول ما يفتح التطبيق)

### التصميم:
```
┌─────────────────────────┐
│                         │
│    خلفية خضرا متدرجة    │
│                         │
│    [أيقونة التطبيق]     │  ← 120px دايرة بيضاء مع الشعار
│    🎧 استمع وتحدث        │  ← نص أبيض، Tajawal Bold
│  برنامج تعليمي للأطفال  │  ← نص أبيض صغير
│                         │
│    [دوائر نبضة loading] │
└─────────────────────────┘
```

**الألوان:** `background: linear-gradient(160deg, #4CAF50, #1B5E20)`

**الأيقونة:** دايرة بيضاء `120×120px` فيها:
- إيموجي كبير: `🎧` فوق
- نص `استمع` أخضر
- نص `وتحدث` برتقالي

**اللودينج:** 3 دوايا صغيرة بتنبض بالتتابع (CSS animation delay)

**بعد 2 ثانية:** انتقل تلقائي للشاشة اللي بعدها

---

## الشاشة 2A: اختر الأفاتار + الاسم (مستخدم جديد)

### التصميم:
```
┌─────────────────────────┐
│  أهلاً! 👋              │
│  إيه اسمك؟             │
│  ┌─────────────────────┐│
│  │   [input الاسم]     ││
│  └─────────────────────┘│
│                         │
│  اختار شخصيتك:          │
│  🐸 🐻 🦊 🐧 🦁 🐙      │  ← 6 أفاتارات
│  [  ] [✓ ] [  ] [  ]   │  ← واحد مختار
│                         │
│  ┌─────────────────────┐│
│  │   يلا نلعب! 🚀      ││  ← btn-primary
│  └─────────────────────┘│
└─────────────────────────┘
```

**الأفاتارات:** `['🐸', '🐻', '🦊', '🐧', '🦁', '🐙']`

**الأفاتار المختار:** دايرة ملونة حواليه + scale(1.2)

**الـ input:**
- border-radius: 16px
- border: 3px solid var(--primary)
- font-size: 20px
- text-align: center
- direction: rtl

**الزرار:**
- يكون disabled لو الاسم فاضي أو مش اتاختار أفاتار
- عند الضغط: `createUser(name, avatar)` ثم `window.location = 'map.html'`

## الشاشة 2B: ترحيب بالعودة (مستخدم موجود)

### التصميم:
```
┌─────────────────────────┐
│                         │
│       [Avatar Emoji]    │  ← 90px في دايرة ملونة
│    أهلاً يا أحمد! 👋    │
│                         │
│  ┌────────┐ ┌────────┐  │
│  │ 🪙 120  │ │ 💎 5   │  │  ← currency chips
│  └────────┘ └────────┘  │
│                         │
│  ┌─────────────────────┐│
│  │   استمر في اللعب 🎮  ││  ← btn-primary
│  └─────────────────────┘│
│                         │
│  [بدء من الأول؟]        │  ← نص صغير link style
└─────────────────────────┘
```

**"بدء من الأول؟"** → يظهر confirm dialog → لو وافق: `resetUser()` ثم يرجع لشاشة 2A

**"استمر في اللعب"** → `window.location = 'map.html'`

## الخلفية العامة للشاشتين 2A و 2B:

مع نجوم وزخارف بسيطة كـ CSS (circles, stars) في الخلفية
